# Contributing

Issues and pull requests are welcome.

- **Bug reports:** include your TV model, Android version, the TV Home version (Settings → About) and, if it crashed, the text from the on-screen crash box or `adb logcat -b crash -d`.
- **Pull requests:** keep changes focused, build with `./build.sh` (see [docs/building.md](docs/building.md)) and test on a real device. Keep the code in plain Java with no third-party runtime libraries.
- **Licensing:** the project is Apache 2.0. By contributing you agree your changes are under the same license. Keep the existing license headers and [NOTICE](NOTICE) intact.
- **Never commit** signing keys or personal data.

The original project's longer contribution guide is in [docs/upstream](docs/upstream).
