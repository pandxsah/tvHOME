# Features

Features marked **New** were added in this fork. The rest comes from [tvOS Launcher](https://github.com/techgenius1/tvOS-Launcher); its original docs are in [upstream](upstream/README.md).

## Home screen

- **New: Media player widget.** Artwork, title, artist and app name of the current or last-played media from any app. OK plays or pauses; hold OK for next/previous or remove. Needs notification access.
- **New: App widgets.** Add a tile that opens any installed app (Settings → Home screen widgets → Add widget).
- **New: Remove widgets in place.** Hold OK on a widget.
- Weather widget with current conditions and tomorrow's forecast.
- Optional widgets, off by default in this fork: Prayer times, Football matches, Most watched.
- Two looks: **Night Scenes** (layered wallpapers and a big glass clock) and **Classic**.
- Liquid Glass dock with adjustable size, app renaming, hiding and moving.
- Continue Watching and a search panel.

## Navigation

- **New:** Dock → widgets → home screen → top-right buttons. The home-screen stop shows "OK · Customize home screen".
- **New:** Down on the dock opens all apps.
- **New: Customize home screen hub** (dock apps, dock size, widgets, wallpaper).

## System tools (inherited)

- Control Center-style panel with quick settings and recent apps
- Remote button mapper (single, double and triple press)
- Built-in debloater (CleanYourTV) and stock-launcher disabler, using on-device ADB
- Profiles, lock screen and screensaver, icon editor, custom and shuffled wallpapers
- Local ADB setup with a secure mode that closes ADB afterwards

## Maintenance

- **New: Updates from this repository's Releases**, with release notes shown in the app.
- **New: On-screen crash report** at the next launch after a crash.

## Not available yet

- AirPlay receiving. Android TV has no built-in AirPlay, and this is not implemented.
- A phone remote. Planned.
- Dragging widgets and apps in an edit mode. Planned.
